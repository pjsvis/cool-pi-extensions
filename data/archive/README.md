# Archive — July 2026 scoring era

Dated snapshots from the first eval era (scoring eval, graded /16, primed-vs-bare
deltas, SIT). **Superseded as an index** by
[`docs/eval-canonical-record.md`](../../docs/eval-canonical-record.md) on
2026-08-23; kept because published writing (`blog/`, `models/`, `debriefs/`)
cites these artifacts by path.

Raw data for this era survives append-only in `../`: `scoring_matrix.jsonl`,
`graded_matrix.jsonl`, `graded_matrix_gemini.jsonl`. These markdown reports are
the *presentation* of that era — immutable, never regenerated.

Do not add new files here. New results go to the JSONL logs; new narrative
reports go to `../` with a date in the filename.
